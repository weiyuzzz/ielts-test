# 雅思口语评分标准（整理版）

> 来源：腾讯文档《雅思口语 9-12 月题库【Part123】》→「考试评分标准-Criteria」小节，
> 以及该节之后的「0–9 分对应评分标准」图片表（中文）。
> 本文把四项评分依据、关键指标与 0–9 分档组织成可检索的结构。
> **中文分档描述是参考译文/项目内结构化转述，不是 IELTS 官方英文原文**；
> 代码侧的唯一事实源是 `src/lib/speaking/band-descriptors.ts`

## 一、评分依据：4 个标准

雅思口语按 9 个分数等级评定，评分依据四个维度，四项权重相同：

| 代号 | 维度 | 英文 |
|---|---|---|
| FC | 流利度与连贯性 | Fluency and Coherence |
| LR | 词汇资源 | Lexical Resource |
| GRA | 语法范围与准确性 | Grammatical Range and Accuracy |
| P | 发音 | Pronunciation |

本项目的评分模块用的就是这四个代号（`src/lib/speaking/scoring.ts`），四项各占 25%，
缺任意一项时不产生总分——这与「四项权重相同」一致。

## 一之二、0–9 分档表（中文参考译文）

> 以下来自原文档图片表的中文描述，仅作项目内部评分参考。
> 官方描述只按整数档给出；每档在代码里对应 1–4 条可引用判据（`<DIM>-B<band>-<nn>`）。

### FC：流利度与连贯性

| Band | 核心判分逻辑 |
|---|---|
| 9 | 表达自然流畅，几乎没有无意义重复或自我修正；停顿主要用于思考内容，而不是寻找词汇或语法；观点充分且逻辑清晰 |
| 8 | 非常流畅，偶有重复或自我修正；停顿主要与内容思考有关；话题展开连贯、衔接自然 |
| 7 | 能持续表达较长内容，整体连贯；偶尔出现找词、重复或自我修正，但不严重影响表达；能灵活使用连接和话语标记 |
| 6 | 能持续表达并讨论话题，但重复、自我修正或犹豫有时影响连贯性；能使用多种衔接方式，但不总是恰当 |
| 5 | 通常可以继续表达，但较依赖重复、自我修正或降低语速；简单表达较流畅，复杂表达容易出现问题；衔接手段有限或使用不当 |
| 4 | 经常停顿、重复和自我修正；表达速度可能较慢；只能较简单地连接句子，整体连贯性经常中断 |
| 3 | 熟悉话题可以表达基本信息，不熟悉话题表达困难；很少有效连接观点，经常无法持续表达 |
| 2 | 大多数词语之前都有明显长时间停顿，只能进行非常有限的交流 |
| 1 | 几乎没有可评估的连续表达 |
| 0 | 缺考或没有可评估的语言表现 |

### LR：词汇资源

| Band | 核心判分逻辑 |
|---|---|
| 9 | 能在各种话题中灵活、精准地使用丰富词汇；搭配、语体、习语和细微含义控制自然 |
| 8 | 词汇范围广，能灵活使用不常见词汇及习语；偶有不准确，但能有效释义替换 |
| 7 | 词汇足以讨论不同话题并充分展开；能够使用部分不常见词汇、习语和自然搭配；有一定词汇选择错误但通常能够成功释义 |
| 6 | 词汇足以讨论话题并清楚表达意思；存在不恰当用词，但通常能够成功进行释义 |
| 5 | 能讨论熟悉及部分不熟悉话题，但词汇灵活性有限；尝试释义，但成功率不稳定 |
| 4 | 熟悉话题能够表达基本意思，不熟悉话题表达困难；词汇选择错误较多，很少有效释义 |
| 3 | 主要使用简单词汇表达个人信息，难以处理不熟悉话题 |
| 2 | 主要使用孤立单词或记忆化表达 |
| 1 | 几乎没有可评估的词汇能力 |
| 0 | 缺考或没有可评估的语言表现 |

### GRA：语法多样性及准确性

| Band | 核心判分逻辑 |
|---|---|
| 9 | 能自然、恰当地使用丰富多样的语法结构，整体准确，仅有极少数非系统性错误 |
| 8 | 能灵活使用广泛的语法结构；绝大多数句子准确，仅偶尔出现不恰当或非系统性错误 |
| 7 | 能灵活使用多种复杂结构；经常能产出准确句子，但仍存在一些语法错误 |
| 6 | 能混合使用简单和复杂结构，但灵活性有限；复杂结构中错误较多，但通常不严重影响理解 |
| 5 | 基本句型通常有一定准确性；复杂结构使用范围有限，错误较多，有时影响理解 |
| 4 | 主要使用基本句型，偶尔能正确使用简单句；从句结构很少，语法错误频繁并可能造成误解 |
| 3 | 尝试使用基本句型但成功率有限，或依赖记忆化表达；错误很多 |
| 2 | 无法稳定产出基本句型 |
| 1 | 几乎没有可评估的语法能力 |
| 0 | 缺考或没有可评估的语言表现 |

### P：发音

| Band | 核心判分逻辑 |
|---|---|
| 9 | 能精准、细腻地运用丰富的发音特征；持续保持自然的节奏、重音和语调；听者几乎不费力即可理解 |
| 8 | 能广泛使用发音特征并保持稳定，偶尔出现偏差；整体非常容易理解，口音对可懂度影响极小 |
| 7 | 展现 Band 6 的积极发音特征，并具备 Band 8 的部分积极特征；整体可懂度较高，但控制尚未完全稳定 |
| 6 | 能使用多种发音特征，但控制程度不一；有时能有效运用重音、节奏和语调，但不够持续；个别发音问题影响清晰度 |
| 5 | 展现 Band 4 的积极特征，并具备 Band 6 的部分积极特征；发音控制存在明显局限 |
| 4 | 发音特征范围有限，控制不稳定；错误发音较频繁，听者有时需要额外努力才能理解 |
| 3 | 只表现出部分基础发音特征；整体发音控制较弱，理解受到明显影响 |
| 2 | 语音经常无法辨认，交流非常困难 |
| 1 | 几乎没有可评估的语音表现 |
| 0 | 缺考或没有可评估的语言表现 |

### 半分规则

- 官方描述**只存在整数档**（0–9），没有独立的「6.5 官方措辞」。
- 半分表示整体表现介于两个相邻整数档之间：评分时对照相邻两档判据，选择最符合整体证据的半分结果。
- `descriptorRefs` 只能引用**真实存在的整数档判据 ID**（`<DIM>-B<band>-<nn>`，band 为单个数字），
  不得虚构 `FC-B6.5-01` 之类的半分档 ID；跨档引用只允许所判 band 相邻的两个整数档。
- 总分按 IELTS 规则取整：平均后小数 .25 进到 .5，.75 进到下一整数（如 6.625 → 6.5、6.75 → 7.0）。

## 二、流利度与连贯性（FC）

**考察什么**：能否以正常的语速、连贯性和较小的表达负担讲话，并把想法与语言有效连接，
形成连贯、有逻辑的表达。

**流利度的关键指标**

- **语速（speech rate）**：理想情况下不应过慢，否则难以在脑中维持词与句之间的连接。
- **表达连续性（speech continuity）**：表达应保持流畅，不应频繁被下列情况打断：
  - 反复重启句子（false starts）
  - 回退修改（backtracking）
  - 无意义的重复（functionless repetition）
  - 频繁停顿找词（pausing to search for words）

**连贯性的关键指标**

- **逻辑顺序**（logical sequencing of spoken sentences）
- **结构标记清晰**（clear marking）：用合理停顿、话语标记（连接词、填充词）标出讲话结构，
  例如讨论、叙述、论证的不同阶段
- **内容相关性**（relevance）：每句话都应服务于当前发言的整体目的
- **衔接手段**（cohesive devices）：句内与句间的逻辑连接词（however、because 等）、代词、连词

## 三、词汇资源（LR）

**考察什么**：可使用的词汇范围，它影响三件事——能讨论的话题范围、表达意义的准确性、
态度表达的清晰程度。

**关键指标**

- **词汇多样性**（variety of words used）
- **词汇的充分性与恰当性**（adequacy & appropriacy），包含：
  - 指称意义（referential meaning）：能否准确表达事物与概念
  - 语体（style）：正式 / 非正式是否合适
  - 搭配（collocation）：含习语表达是否自然
  - 态度表达（attitude）：能否表达赞同、中立或反对
- **同义替换能力**（paraphrase ability）：词汇不够时能否换一种说法，允许有或没有明显停顿

## 四、语法范围与准确性（GRA）

**考察什么**：能否准确、恰当地使用句法结构满足口语考试要求，同时看语法资源是否丰富。

**范围的关键指标**

- 口语句子的长度（length of spoken sentences）
- 从句的恰当使用（appropriate use of subordinate clauses）
- 动词短语的复杂性（complexity of the verb phrase）：进行时 / 完成时、情态、被动语态
- 其他短语的复杂性（complexity of other phrases）：前置修饰与后置修饰
- 句型结构多样性（range of sentence structures）：为突出信息重点而调整成分位置

**准确性的关键指标**

- **错误密度**（error density）：一定话语量中语法错误的数量
- **错误的交际影响**（communicative effect of error）：错误是否影响理解、清晰度或准确性

## 五、发音（P）

**考察什么**：能否准确且持续地使用多种语音特征，把有意义的信息清晰地传达出去。

**关键指标**

- 把语音切分为有意义的表达单元：句内自然分段（chunking）
- 节奏与重音（rhythm & stress timing）、连读（linking）：连音、弱读、省音（elision）
- 重音与语调（stress & intonation）：强调重点（emphatic）或对比（contrastive）
- 发音准确性（sound production）：单词重音（word stress）、元音与辅音（vowel & consonant）
- 听者理解所需付出的努力（是否费劲）
- 口音对理解的整体影响（accent intelligibility）

## 六、这份整理能干什么、不能干什么

**能**：

- 作为写作/练习时的自检清单：每个维度下列出的指标就是「考官在听什么」。
- 与本项目报告页的四项维度一一对应，便于把扣分点落到具体指标上。
- 为评分 prompt 提供结构化判据：`band-descriptors.ts` 的每条判据都可以被模型引用、
  在报告里展示为「依据第 X 档第 Y 条」（`descriptor_refs`，自 Phase 3 起持久化）。

**不能**：

- **不能冒充官方原文**。中文分档是参考译文，判据措辞是项目内结构化转述；
  官方标准以 IELTS 官网与《Official IELTS Practice Materials》为准。
- **不能据此机械算分**。指标是描述性的，不是阈值——词数、语速、复杂句数量、MATTR
  等统计量只能进入「学习诊断」模块，任何公式都不能直接产出 band；band 只能由
  LLM 对照判据判断（发音维度只能由音频 Provider 证据支持判断）。
- 本项目在没有接入 LLM 评分时输出 `unscored`，不会用代理指标冒充 band；
  启发式统计一律标注为「学习诊断 Diagnostic Metrics」。

## 附：与题库学习素材的衔接

题库素材里的「思路速记 / 语料扩展」按上述维度组织：

| 评分维度 | 对应的学习素材 |
|---|---|
| FC | 思路速记的段落顺序、连接词（Note 里的 but / so / when 说明） |
| LR | 语料扩展（同义表达、搭配）、关键词速记 |
| GRA | 示范答案里的从句与复杂结构（Note 里的 `I don't need to…`、`what really struck me is…`） |
| P | 跟读（Shadowing）与逐段 TTS，用于节奏、重音与连读的模仿 |

素材本身是**练习资料**，不是评分依据；`/speaking/questions` 与练习页都按这个定位标注。
