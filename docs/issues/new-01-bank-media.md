# [Content] 题库素材未导入：高分范文 / 思路解读 / 关键词速记 / 跟读音频，练习模式 shadowing 缺失

<!-- labels: content, enhancement -->

## 背景

腾讯文档《雅思口语 9–12 月题库》除题目外，每题还带一整组备考素材。当前只导入了「考什么」，
没有导入「怎么答」，所以产品里能模考、能评分，但练不了。

## 现状（已核实）

- `src/data/question-banks/2026-09-12-mainland.json` 只有 `text` / `textZh` / `cuePoints` / `type` / `examinees`。
- 文档中的**高分回答、思路解读、关键词速记、语料扩展、跟读 mp3（如 `Noise-1/2/3.mp3`）全部未导入**。
- `src/` 下没有任何 shadowing / 跟读相关实现（`grep -rn shadow src` 为空）。
- 考后报告里的改写建议是「针对用户原句」生成的（这是我们的优势，**不要用题库范文替换它**）。

## 建议做法

1. 题库 schema 增加 `sampleAnswer`、`ideaNotes`、`keyPhrases`、`followAudio`（数组），导入脚本按题块解析。
2. 只在**考后 / 练习**露出，且必须标注「题库预置范例，非针对你的回答」，避免考生背模板。
3. shadowing：示范音频 → 录音 → 与示范对比（可复用现有 `RecordingSession` 与音量可视化），
   评分只做「是否跟上 / 漏词」，不要用语言模型硬评发音。
4. 音频文件放 `public/audio/follow/`，注意本 issue 与「预置音频通路」issue 的字段设计保持一致。

## 验收

- 题库详情页能看到某道题的范文、思路、关键词
- 练习模式可选择一道题走完 shadowing 流程（示范 → 跟读 → 对比）
- 模考中**不出现**任何范文

## 阻塞 / 风险

- 文档里的素材是第三方整理内容，商用前需确认授权；若授权不明，建议只借结构与分类，文本自行编写。
- 音频素材需要实际下载与体积评估（54 题卡 × 5 题 × 多条音轨）。
