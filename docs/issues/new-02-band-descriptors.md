# [Scoring] 0–9 分档描述符缺失，AI 评分只拿到「关键指标」而非分档原文

<!-- labels: scoring, help wanted -->

## 背景

`src/lib/speaking/band-descriptors.ts` 目前固化了四项（FC / LR / GRA / P）的**关键指标**、
各 Part 的期望长度与 4×25% 权重，并注入评分 prompt（`speaking-criteria-v2.0`）。

但评分标准里真正的「0–9 分档描述」在腾讯文档中是**图片 / 嵌入表格**，接口没有返回文字，
所以当时**没有编造**，prompt 里只有指标没有分档措辞。

## 影响

- LLM 只能凭自身先验对齐 band，同一段回答在不同模型上可能差 0.5–1 分。
- 无法做「改造前后同一样本的单调性回归」，因为缺少可引用的分档锚点。

## 建议做法

1. 人工把四项 × 0–9 分档描述录入为结构化数据（每档 2–4 条判据），放进 `band-descriptors.ts` 并纳入版本号。
2. prompt 改为「按档位判据逐条比对，给出所依据的档位条目编号」，报告页可展示引用到的判据。
3. 用现有 LOW / MID / HIGH 样本 + 文档里的高分范例做回归：同一文本评分不得随模型更换跳动超过 0.5。
4. 发音维度保持「不评价口音」，只按 chunking / 节奏 / 语调 / 音素准确 / 听者费力程度分层。

## 验收

- `SCORING_PROMPT_VERSION` 升版，prompt 中含可引用的分档条目
- 报告 findings 能标出「依据第 X 档第 Y 条」
- 回归样本集通过，且无 AI 时仍然是 `unscored`（不伪造分数）
